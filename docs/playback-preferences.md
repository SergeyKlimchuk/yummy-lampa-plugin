# Озвучка, источник и плеер

Настройки по умолчанию находятся в **Настройки → YummyAnime → Воспроизведение**:

- **Источник видео по умолчанию** — Kodik, CVH, Sibnet и другие поддерживаемые источники либо «Авто».
- **Озвучка по умолчанию** — вариант из озвучек, уже встреченных в загруженных аниме. Название также можно ввести вручную.
- **Приложение для воспроизведения** — внутренний плеер Lampa, внешний Android-плеер или запрос перед запуском. Внешний плеер доступен только на Android. На LG WebOS прямой поток воспроизводит внутренний плеер Lampa; отдельные источники могут открывать собственный встроенный плеер.

Кнопка «Серии и озвучка» открывает экран выбора: текущие озвучка и источник, кнопка запуска выбранной серии и список серий. Фокус сразу находится на запуске. Изменение озвучки или источника сохраняется **только для этого аниме** и само по себе не запускает видео. Источники показываются только для выбранной озвучки; количество серий и последняя серия относятся к этой конкретной паре.

При новом открытии порядок выбора такой:

1. Сохранённая озвучка и источник этого аниме.
2. Точная озвучка и источник последнего просмотренного видео из истории аккаунта, если это видео ещё доступно.
3. Настройки по умолчанию.
4. Старые записи истории без точного ID видео, затем доступный автоматический вариант.

Отключённые в настройках источники в подборе не участвуют. Если сохранённая пара недоступна, плагин сообщает о замене и подбирает доступный вариант; прежнее предпочтение сохраняется, пока вы явно не измените его. При смене озвучки сохраняется номер серии, если она есть у нового источника; иначе показывается предупреждение и доступная серия. Позиция просмотра переносится только на ту же серию.

Глобальные предпочтения изменяются только в разделе **Настройки → YummyAnime → Воспроизведение**. Изменения в окне просмотра автоматически сохраняются отдельно для текущего аниме. **«Сбросить выбор»** удаляет отдельный локальный выбор. После сброса сначала учитывается последнее просмотренное видео, затем общие настройки.

Явный выбор озвучки и источника хранится локально на устройстве. Приложение для воспроизведения задаётся только в общих настройках и применяется ко всем аниме; старые индивидуальные переопределения приложения игнорируются без потери озвучки и источника. Запоминаются до 200 аниме и до 160 названий озвучек. Длинный список серий выводится страницами по 12, выбор озвучек и источников — по 30 вариантов. Для воспроизведения и автоматического перехода сохраняется полный плейлист.

Офлайн-макет раздела «Источник / озвучка / серии» использует только сохранённые метаданные публичного снимка. В нём выбор действует до перезагрузки страницы, а потоки и внешние плееры не запускаются.


## Отметки серий

В списке серий зелёный цвет и галочка означают подтверждённое завершение, жёлтый — начатую серию с сохранённой позицией. Если длительность известна, рядом показан процент. Текущая серия и фокус пульта выделяются отдельно.

Плагин читает `watched` из свежего ответа `GET /anime/{id}/videos` при открытии окна, после возврата из плеера и по кнопке «Обновить просмотр». Завершение определяется явными положительными `completed` / `finished` или общей эвристикой по известной длительности. У видео длительностью от 15 до 40 минут допускается непросмотренный хвост до 5 минут, но не больше четверти серии: 19:00 из 24:00 уже считается завершением, 18:59 — ещё продолжением. Для коротких видео и фильмов вне этого диапазона сохраняется порог 95%. Без известной длительности завершение определяется только явной отметкой. Это оценка по времени, а не распознавание титров; правило само по себе не перематывает видео и не запускает следующую серию. Начало просмотра не считается завершением. Отметки объединяются по номеру серии между озвучками и источниками; пропущенные серии не закрашиваются по последнему номеру.

Внутренний плеер Lampa уже отправляет позицию в аккаунт YummyAnime раз в минуту и при паузе/закрытии. Настройка «Автосинхронизация прогресса» управляет отправкой. Внешние приложения и сторонние iframe не всегда возвращают точный таймлайн: для них нельзя обещать определение завершения по фактическому просмотру. Сохранённые сайтом отметки при этом загружаются обычным обновлением.

Локальные наблюдения хранятся отдельно для каждого аккаунта: до 200 аниме и 5000 отдельных серий, без адресов потоков и токенов. Завершение записывается сразу, частичный прогресс — с ограничением частоты. Старые ответы и отложенные операции другого аккаунта не применяются к текущему. Обновление статусов меняет только текущие кнопки серий и сохраняет фокус; фонового опроса и анимаций нет.


## Восстановление озвучки и источника с сайта

История аккаунта возвращает `video_id`. Список `GET /anime/{id}/videos` связывает
этот ID с озвучкой и видеосервисом, поэтому плагин восстанавливает фактически
просмотренную пару на другом устройстве при обычной синхронизации истории.
Явный локальный выбор конкретного аниме сохраняет приоритет; общие настройки
используются для аниме без такого выбора и без доступного просмотренного видео.

Простое переключение списка озвучек или источника без просмотра не имеет
отдельного метода синхронизации в [официальной OpenAPI](https://api.yani.tv/swagger).
В [схеме](https://api.yani.tv/swagger/swagger-ui-init.js) `PUT /video/{id}` сохраняет
данные просмотра, а `PATCH /profile` не содержит видеопредпочтений. Плагин не
создаёт фиктивные просмотры ради сохранения настройки. Выбор без просмотра
по-прежнему автоматически запоминается на текущем устройстве.


## Штатный плейлист Lampa

При воспроизведении во встроенном плеере YummyAnime передаёт в штатный плейлист полный список серий выбранной озвучки и источника. В панели плеера кнопка **«Плейлист»** открывает этот список: выберите любую серию стрелками пульта и нажмите OK. Так можно вернуться и к предыдущей серии. Штатная кнопка **«Следующая серия»** открывает соседнюю серию, когда она доступна.

Прямой адрес потока получается при выборе серии. Обычным переключением управляет Lampa: сама завершает предыдущий поток, запускает выбранный как продолжение воспроизведения и переносит поддерживаемые параметры плеера. Озвучка и источник при этом сохраняются.

Позиция покидаемой серии записывается в историю без принудительной отметки «просмотрено». Сохранённая позиция целевой серии передаётся штатному механизму продолжения просмотра; дальнейшее поведение определяется настройками плеера Lampa. Уже просмотренная серия при повторном выборе запускается с начала. Если получить прямой поток не удалось, плеер закрывается с сообщением, чтобы можно было выбрать другую серию или источник.

В **Настройки → YummyAnime → Воспроизведение → Автопереход Lampa** находится кнопка открытия штатных настроек плеера. Автоматический запуск следующей серии определяется общей настройкой Lampa и относится ко всем плагинам. YummyAnime не меняет её при запуске и не переносит в неё старую индивидуальную настройку автоперехода.

Штатный плейлист используется во встроенном плеере Lampa. Собственные веб-плееры источников управляют сериями самостоятельно.


## Последняя позиция и отложенная синхронизация

Для одной серии выбирается последняя известная позиция по времени обновления, а не наибольшее число секунд. Перемотка назад и явная позиция `0` при повторном запуске сохраняются. Даты сайта в секундах или ISO сравниваются с локальными миллисекундами; при равных или неизвестных датах приоритет получает локальная запись. Отсутствие позиции отличается от остановки на нуле.

Изменения прогресса, категорий и оценок сохраняются перед отправкой. Запросы одного объекта выполняются последовательно; одиночные и пакетные обновления видео также согласованы между собой. Новое изменение заменяет устаревшее, сохраняя остальные серии из пакета. Очередь привязана к аккаунту. Первый сетевой сбой, тайм-аут или временный ответ HTTP 408/425/429/5xx оставляет изменение для повтора; явная отмена и постоянный отказ 4xx не повторяются.

Сохранённая очередь проверяется после запуска, восстановления подключения и каждые 15 минут. Ограничения очереди остаются прежними: 100 записей и до 8 повторных временных HTTP-отказов для одной записи. Если хранилище недоступно, отправка продолжает работать с очередью в памяти текущего сеанса; пережить перезапуск такая очередь не сможет.

## Завершение и продолжение возле титров

Один и тот же порог используется для отметок серий, старого локального журнала, истории с YummyAnime и очереди «Продолжить просмотр». Явные отметки завершения с сайта сохраняются при импорте даже при неизвестной длительности; строки `false` и `0` не считаются такими отметками. Синтетическая запись следующей серии не наследует завершение предыдущей.

Фактические `time` и `duration`, сохраняемые локально и отправляемые на YummyAnime, остаются точными: остановка на 19:00 из 24:00 отправляется как 1140 из 1440 секунд. Плагин не подменяет это концом видео. Настройки категорий всего аниме не изменяются.

Для незавершённых коротких видео и фильмов позиция на 90–95% также передаётся штатному плееру. Ограничивается только начальная процентная подсказка в `timeline`, чтобы Lampa не отказалась восстанавливать точный `timeline.time` из-за собственного порога 90%. После запуска плеер пересчитывает процент по реальному времени. Настройки Lampa «Продолжать / Спрашивать / Сначала» сохраняют приоритет.
