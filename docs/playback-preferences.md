# Озвучка, источник и плеер

Настройки по умолчанию находятся в **Настройки → YummyAnime → Воспроизведение**:

- **Источник видео по умолчанию** — Kodik, CVH, Sibnet и другие поддерживаемые источники либо «Авто».
- **Озвучка по умолчанию** — вариант из озвучек, уже встреченных в загруженных аниме. Название также можно ввести вручную.
- **Приложение для воспроизведения** — внутренний плеер Lampa, внешний Android-плеер или запрос перед запуском. Внешний плеер доступен только на Android. На LG WebOS прямой поток воспроизводит внутренний плеер Lampa; отдельные источники могут открывать собственный встроенный плеер.

Кнопка «Серии и озвучка» открывает экран выбора: текущие озвучка и источник, кнопка запуска выбранной серии и список серий. Фокус сразу находится на запуске. Изменение озвучки или источника сохраняется **только для этого аниме** и само по себе не запускает видео. Источники показываются только для выбранной озвучки; количество серий и последняя серия относятся к этой конкретной паре.

При новом открытии порядок выбора такой:

1. Сохранённая озвучка и источник этого аниме.
2. Точная озвучка и источник последнего просмотренного видео из истории аккаунта, если это видео ещё доступно.
3. Настройки по умолчанию.
4. Старые записи истории без точного ID видео, затем доступный автоматический вариант.

Отключённые в настройках источники в подборе не участвуют. Если сохранённая пара недоступна, плагин сообщает о замене и подбирает доступный вариант; прежнее предпочтение сохраняется, пока вы явно не измените его. При смене озвучки сохраняется номер серии, если она есть у нового источника; иначе показывается предупреждение и доступная серия. Позиция просмотра переносится только на ту же серию.

Глобальные предпочтения изменяются только в разделе **Настройки → YummyAnime → Воспроизведение**. Изменения в окне просмотра автоматически сохраняются отдельно для текущего аниме. **«Сбросить выбор»** удаляет отдельный локальный выбор. После сброса сначала учитывается последнее просмотренное видео, затем общие настройки.

Явный выбор озвучки и источника хранится локально на устройстве. Приложение для воспроизведения задаётся только в общих настройках и применяется ко всем аниме; старые индивидуальные переопределения приложения игнорируются без потери озвучки и источника. Запоминаются до 200 аниме и до 160 названий озвучек. Длинный список серий выводится страницами по 12, выбор озвучек и источников — по 30 вариантов. Для воспроизведения и автоматического перехода сохраняется полный плейлист.

Офлайн-макет раздела «Источник / озвучка / серии» использует только сохранённые метаданные публичного снимка. В нём выбор действует до перезагрузки страницы, а потоки и внешние плееры не запускаются.


## Отметки серий

В списке серий зелёный цвет и галочка означают подтверждённое завершение, жёлтый — начатую серию с сохранённой позицией. Если длительность известна, рядом показан процент. Текущая серия и фокус пульта выделяются отдельно.

Плагин читает `watched` из свежего ответа `GET /anime/{id}/videos` при открытии окна, после возврата из плеера и по кнопке «Обновить просмотр». Завершение определяется явными `completed` / `finished` или просмотром не менее 95% известной длительности. Начало просмотра не считается завершением. Отметки объединяются по номеру серии между озвучками и источниками; пропущенные серии не закрашиваются по последнему номеру.

Внутренний плеер Lampa уже отправляет позицию в аккаунт YummyAnime раз в минуту и при паузе/закрытии. Настройка «Автосинхронизация прогресса» управляет отправкой. Внешние приложения и сторонние iframe не всегда возвращают точный таймлайн: для них нельзя обещать определение завершения по фактическому просмотру. Сохранённые сайтом отметки при этом загружаются обычным обновлением.

Локальные наблюдения хранятся отдельно для каждого аккаунта: до 200 аниме и 5000 отдельных серий, без адресов потоков и токенов. Завершение записывается сразу, частичный прогресс — с ограничением частоты. Старые ответы и отложенные операции другого аккаунта не применяются к текущему. Обновление статусов меняет только текущие кнопки серий и сохраняет фокус; фонового опроса и анимаций нет.


## Восстановление озвучки и источника с сайта

История аккаунта возвращает `video_id`. Список `GET /anime/{id}/videos` связывает
этот ID с озвучкой и видеосервисом, поэтому плагин восстанавливает фактически
просмотренную пару на другом устройстве при обычной синхронизации истории.
Явный локальный выбор конкретного аниме сохраняет приоритет; общие настройки
используются для аниме без такого выбора и без доступного просмотренного видео.

Простое переключение списка озвучек или источника без просмотра не имеет
отдельного метода синхронизации в [официальной OpenAPI](https://api.yani.tv/swagger).
В [схеме](https://api.yani.tv/swagger/swagger-ui-init.js) `PUT /video/{id}` сохраняет
данные просмотра, а `PATCH /profile` не содержит видеопредпочтений. Плагин не
создаёт фиктивные просмотры ради сохранения настройки. Выбор без просмотра
по-прежнему автоматически запоминается на текущем устройстве.


## Переключение серий во встроенном плеере

В стандартной панели Lampa появляются кнопки **«Предыдущая серия»** и **«Следующая серия»** с номерами соседних серий. Выберите кнопку стрелками пульта и нажмите OK. На границе списка соответствующая кнопка недоступна; при единственной серии кнопки не добавляются.

Переключение сохраняет озвучку и источник текущего аниме и работает даже при выключенном автопереходе. Позиция покидаемой серии сохраняется без принудительной отметки «просмотрено». Незавершённая целевая серия продолжается с сохранённой позиции, а уже просмотренная запускается с начала.

Плагин сначала закрывает старый поток и только после освобождения видеоплеера запускает новый. Повторное нажатие во время перехода не создаёт ещё один запуск. Если источник не отдаёт прямой поток, плагин сообщает об ошибке и возвращает управление предыдущему экрану. Эти кнопки относятся к встроенному плееру Lampa; собственные веб-плееры источников управляют сериями самостоятельно.
