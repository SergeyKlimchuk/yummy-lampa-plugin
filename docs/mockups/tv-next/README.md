# YummyAnime: предложение нового UX для телевизора

Откройте `index.html`. Стрелки — фокус, OK/Enter — выбор, удержание OK — контекстные действия, Back/Escape — предыдущий слой. Мышь поддерживается; правая кнопка соответствует удержанию. На небольшом экране компоновка уплотняется. Разделы доступны напрямую: `#home`, `#search`, `#lists`, `#detail`, `#watch`, `#settings`.

Это интерактивное предложение, а не замена рабочего плагина. Нет авторизации, запросов к API, отправки категорий, сохранения настроек на сайте или запуска видео. Из внешней сети загружаются только публичные постеры. Публичные названия, описания, оценки, серии и пары озвучка/источник взяты из существующего `prototype-data.js`. Личные категории и прогресс — явно демонстрационное состояние; счётчики вычисляются из него. Для тайтлов без сохранённых переводов макет показывает отсутствие данных, не подставляет чужие серии.

## Что изменено в предложении

- На главной фокус сразу на продолжении. Открытие карточки доступно рядом и через удержание. Нет большого рекламного баннера или автопревью.
- Постоянная навигация: Главная, Поиск, Мои списки, Каталог; остальные направления под «Ещё», внизу отдельно «Аккаунт» и под ним «Настройки». Нет дублирования настроек/аккаунта в шапке.
- Контекстные действия используют компактную панель по высоте. Длинные варианты используют правую панель, сохраняя исходный экран. Вложенных окон нет, Back возвращает фокус на вызвавший элемент.
- В карточке: название → оценки → тип и теги → серии и время → действия → категории → описание → переводы → метаданные → комментарии. Основная кнопка заметнее вторичных; рядом есть прямой переход «Серии и озвучка». Для продолжения при готовых предпочтениях макет сразу показывает запрос запуска, без дополнительного подтверждения. Статический текст не попадает в маршрут пульта.
- Из основной кнопки карточки Down ведёт к текущей категории. «Любимое» независимо от категории. Поиск и списки показывают цветную полосу под постером.
- В просмотре серия, озвучка и источник видны одновременно. Выбор меняет только нужные поля; серии остаются на экране. Общие предпочтения находятся только в настройках. Для LG приложение-плеер фиксировано на Lampa.
- В списках — вкладки категорий и единая сетка. Удержание постера открывает категории, обычный OK — карточку. Сортировка использует ту же панель выбора.
- Фокус — светлая рамка; выбранное значение — галочка; категория — собственный цвет и подпись. Коралловая кнопка с тёмной надписью означает главное действие.

## На какие решения опирается предложение

Это выбор подходящих принципов, а не доказанный рейтинг того, что нравится большинству. Публичные релизы компаний не заменяют тест с владельцем телевизора.

| Источник | Подтверждённый принцип | Применение здесь |
|---|---|---|
| [Android TV: Navigation](https://developer.android.com/design/ui/tv/guides/foundations/navigation-on-tv), [Focus system](https://developer.android.com/design/ui/tv/guides/styles/focus-system) | Прямые маршруты по стрелкам, минимум уровней, предсказуемый Back и один различимый фокус | Группы элементов, возврат на ту же кнопку, отсутствие фокуса на статическом тексте |
| [Apple: Remotes](https://developer.apple.com/design/human-interface-guidelines/remotes) | Знакомое поведение пульта и понятная связь направления с движением фокуса | Стандартные стрелки/OK/Back, удержание дополняет видимые действия |
| [YouTube: Designing a richer TV experience](https://blog.youtube/news-and-events/designing-a-richer-youtube-experience-for-your-tvs/) | Дополнительная информация рядом с главным содержимым с сохранением контекста; авторы ссылаются на своё исследование пользователей | Боковой выбор озвучки и источника рядом с сериями; визуальные эффекты оттуда не перенесены |
| [Plex: Audio/subtitle preferences](https://support.plex.tv/articles/204985278-account-audio-subtitle-language-settings/) | Ручной выбор для конкретного материала имеет приоритет над автоматическими предпочтениями | Общие настройки и отдельный запомненный выбор аниме с понятной подписью |
| [Netflix: TV layout](https://www.netflix.com/tudum/articles/netflix-new-tv-layout) | Доступные направления, личный раздел и информация о тайтле до запуска | Чёткая навигация и личные списки; динамические рекомендации и большое промо не добавляются |

## Целевые маршруты с пульта

Счёт начинается с указанного фокуса, а не из любого места приложения. Реальная скорость и удобство ещё требуют проверки на LG.

| Старт | Действие | Маршрут |
|---|---|---|
| Первый вход на главную | Продолжить | 1 OK |
| Основная кнопка карточки | Текущая категория | 1 Down; затем Left/Right + OK для изменения |
| Продолжение на главной | Открыть карточку | 1 Down + OK; дополнительно удержание → Down + OK |
| Поле озвучки/источника | Изменить | OK → стрелки → OK; панель закрывается на прежнюю кнопку |
| Постер в списке | Изменить категорию | Удержание → стрелки → OK |
| Любая панель | Вернуться | 1 Back, тот же фокус |

## Лёгкость и перенос в рабочий плагин

Макет использует обычные HTML/CSS, системный шрифт и существующие профили масштаба из `src/ui-scale.js`. Нет библиотек интерфейса, анимаций, blur, теней, увеличения постеров или фонового опроса. На экране до 12 постеров/серий; картинки ленивые. Панель отдельная от основного DOM. Просмотренные серии и частичный прогресс различаются текстом и цветом. Настройки масштаба 80–200% используют текущую нормализацию.

Порядок переноса: (1) общий компонент выбора и возврат фокуса; (2) окно озвучки/источника и короткое меню продолжения; (3) упрощение маршрута карточки; (4) главная и единые списки; (5) остальные экраны. Существующие синхронизация, авторизация, журнал прогресса и доступные источники при этом переиспользуются.

Перед выпуском: проверить на реальном LG поиск, 1 Down к категории, сохранение выбора и позиции после Back, быстрое переключение списков, длинные названия, пустые ответы, реальную сеть и 4K. Макет не доказывает частоту кадров телевизора.
