# Реальные экраны аккаунта и службы YummyAnime

Источник: текущий форк `/mnt/main/projects/external/yummy-lampa-plugin`. Полный машинно-читаемый перечень полей, действий, состояний и исходников — `account-audit.json`.

| Экран | Реальный маршрут / компонент | Что можно показывать в макете |
|---|---|---|
| Аккаунт | `yani/account` / `yani_account` | Аватар при наличии, имя, ID, описание, статус входа/блокировки; дата регистрации/посещения, роли, счётчики сообщений/уведомлений/аниме; ссылки на уведомления, подписки, рецензии и выход |
| Статистика | Часть `yani_account`, отдельного маршрута нет | Шесть категорий: количество и время просмотра. Дополнительно до 12 строк жанров, оценок и типов с `count`; пустые группы скрыты |
| Мои списки | `yani/user-lists` / `yani_user_lists` | 6 категорий + история; до 10 постеров на строку и «Ещё», общее количество, цифровые/цветные кнопки пульта |
| Полная категория | `yani/account/list/{key}` / `yani_account_list` | Карточки и прогресс, количество, сортировка по добавлению/прогрессу/рейтингу/году/названию; локальные страницы по 30 |
| Продолжить просмотр | `yani/continue-watching` / `yani_history`, `mode:continue` | Постер, аниме, серия и сохранённый прогресс; переход к следующей серии при корректном потолке эпизодов; локальная и серверная история |
| История | `yani/history` / `yani_history`, `mode:history` | Карточки последних просмотров, серия, позиция, озвучка и плеер при наличии; серверная пагинация по 30 |
| Подписки | `yani/subscriptions` / `yani_subscriptions` | Сетка аниме из подписок. Управления подпиской в этом компоненте нет; карточка открывает детали |
| Уведомления | `yani/notifications` / `yani_notifications` | Тип, текст, дата, прочитано/нет, группы сегодня/вчера/ранее, переход к аниме при распознанной цели, прочитать всё, удалить всё, загрузить ещё |
| Вход | `yani/auth` / `yani_auth` | Логин/email, пароль с маской, кнопка входа. Для авторизованного пользователя — обновить токен и выйти |
| Статус | `yani/status` / `yani_status` | 3 часа/день/неделя/месяц, доступность/ошибки/средняя задержка/время снимка, домены и история состояний, обновить |
| Настройки | Общий `Lampa.Settings.create('yani')` | Аккаунт, язык, воспроизведение, источники, серверы-интеграции, кнопка/рейтинги Lampa, видимость разделов, информация и условия |
| Условия | `showUsagePolicy()` overlay / `yani_policy` controller | Заголовок, 4 уже существующих абзаца, одна закрывающая кнопка; нет обязательного онбординга |

## Чтобы не добавить вымышленные возможности

- У профиля нет редактирования имени/аватара, формы сообщений, друзей или платежей. Счётчик сообщений — только информация.
- Статистика не имеет фильтра периода, тепловой карты активности, социальных сравнений и кликабельной детализации строк.
- Категории фиксированные. Основной статус один; любимое независимо. Нет пользовательских папок, тегов, массового редактирования и автоимпорта стандартных отметок Lampa.
- В уведомлениях реализовано удаление **всех**, но не кнопка удаления отдельной строки. Число непрочитанных в заголовке считается по загруженным строкам. Произвольные внешние ссылки и переходы к комментариям не открываются.
- Вход не имеет QR-кода, OAuth, регистрации, сброса пароля, 2FA или встроенной CAPTCHA. Собственный API-ключ официальному плагину не нужен.
- На LG/webOS плеер зафиксирован внутренний. Выбор Android-плеера и интеграция YummyTV показываются только на соответствующей платформе.
- «Очистить историю» в настройках удаляет только локальный `yani_playback_history`, не серверную историю.
- Статус сервисов — снимок YummyStatus, не живые измерения CPU/RAM/скорости сети телевизора.

## Осторожно с фикстурами

Файлы `tests/fixtures/yani-api/*.json` содержат анонимизированные синтетические примеры. В `lists.json` искусственный каталог категорий не соответствует использованию реального `/users/{id}/lists` как массива аниме. Время категории Account берёт из `stats[].seconds` с `stats[].list.id`, а не из fixture `time/id`. Не переносить эти значения как проверенные реальные счётчики пользователя.

Уведомление с `object_id` ещё не имеет прямого `anime_id`; текущая навигация использует `anime_id/animeId` или slug только для уведомления о серии. HTML текст очищается до обычного текста.
