# Проверка облегчённого интерфейса

Проверено 25 октября 2026 года. Рабочие JavaScript-модули форка и его CSS запускались в браузере компьютера с тестовыми ответами API и адаптером интерфейсов Lampa. Это не замер FPS на LG OLED48A3RLA и не замена проверке установленного приложения на телевизоре. Реальный аккаунт не использовался.

## Результаты

Одинаковые 12 карточек после первоначального построения, 100 повторных проходов декоратора:

| Показатель | До | После |
| --- | ---: | ---: |
| Время повторных проходов | 126.6 мс | 23.4 мс |
| Записи мутаций DOM | 4800 | 0 |
| Чтения вычисленного стиля | 2400 | 1200 |

Одно чтение размера шрифта на карточку сохранено намеренно: при изменении масштаба Lampa нельзя использовать устаревшие приоритеты значков. Неизменившиеся элементы не пересоздаются. Это измерение конкретной повторной операции; оно не означает ускорение всех экранов во столько же раз. Время загрузки каталога и интервалы кадров пульта в этом тестовом окружении существенно не изменились.

В проверке 22 рабочих компонентов не обнаружены активные градиенты, тени, фильтры, анимации или CSS-переходы внутри интерфейса плагина. Плеер и системные окна Lampa используют управление самого приложения. Часть результатов показывала пустые состояния; наполненные длинные списки дополнительно проверены runtime-тестами.

После 1-го, 15-го и 30-го открытия уведомлений оставалось по 62 элемента DOM; после destroy — 0, ожидающих тестовых запросов — 0. Это проверка роста DOM и освобождения экрана, а не измерение всей памяти браузера.

## Ограничения нагрузки

- Расписание: первоначально 20 строк выбранного дня; следующие доступны по «Ещё». Подробности подгружаются для выбранной строки, не более двух запросов одновременно.
- Ленты и подписки: стандартные страницы по 30 карточек, остальные результаты сохраняются для следующих страниц.
- Серии: до 60 пунктов за один выбор и переходы между диапазонами. Полный плейлист сохраняется для автоматического продолжения; проверены 1403 серии и возврат к сохранённой серии после смены источника.
- Профиль: компактные счётчики вместо полной коллекции; категория получает свежий состав при открытии.
- График статуса: не более 48 столбцов на домен, аварийные интервалы сохраняются при объединении.
- При смене аккаунта и закрытии/приостановке страницы поздние ответы не показывают старые данные и не возвращают фокус на скрытый экран.

## Регрессионная проверка

Все 109 файлов `tests/*.test.js` прошли. Новые runtime-проверки покрывают мутации карточек, масштаб интерфейса, пагинацию, порядок ответов, смену аккаунта и жизненный цикл экранов. `tests/lite-rendering-budget.test.js` запрещает дорогостоящие эффекты в поставляемом CSS и проверяет одинаковый порядок зависимостей загрузчика и сборки.

Сборка: `node build.js`. Тесты запускаются из корня проекта: каждый файл `tests/*.test.js` через Node. На Node 26 использован флаг `--no-experimental-global-navigator`, поскольку старый тест резолвера задаёт собственный navigator. Рабочий код из-за этого не менялся; CI проекта использует Node 20.
